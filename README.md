# JobClaw

JobClaw is an AI-powered job search tool that converts natural language job requirements into structured search intent.

Users can select an LLM provider, edit the system and user prompts, and generate validated JSON output for job searches.

## Current Features

- OpenAI and Ollama provider support
- Provider selection using a factory pattern
- Editable system and user prompts
- Structured LLM responses using Zod
- Search intent validation
- Next.js API route
- React frontend with Axios

## Tech Stack

- Next.js
- TypeScript
- Zod
- Axios
- OpenAI SDK
- Ollama
